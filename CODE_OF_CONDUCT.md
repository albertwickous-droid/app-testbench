# 行为准则 / Code of Conduct

## 承诺 / Our pledge

我们希望项目参与者在交流中不受骚扰，并能在一个尊重差异、重视证据和隐私的环境中协作。

We want participation in this project to be harassment-free and welcoming regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, experience level, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## 期望行为 / Expected behavior

- 尊重他人，讨论具体问题，不攻击个人。
- Critique code and ideas, not people.
- 提问时提供可复现证据，同时尊重隐私。
- Assume good faith while asking for evidence.
- 不发布他人的截图、日志、token、账号或个人信息。
- Respect privacy: do not post someone else's screenshots, logs, tokens, or account data.
- 接受维护者关于项目范围的决策。
- Accept maintainers' decisions about project scope.

## 不可接受行为 / Unacceptable behavior

- 骚扰、威胁、歧视、性化关注或人身攻击。
- Harassment, threats, discriminatory language, sexualized attention, or personal attacks.
- 未经许可公开私人信息。
- Publishing private information without permission.
- 恶意扰乱讨论或持续进行 bad-faith 参与。
- Deliberately disruptive or bad-faith participation.
- 鼓励未授权访问设备、应用或账号。
- Encouraging unauthorized access to devices, applications, or accounts.

## 执行 / Enforcement

维护者可以编辑或移除违反本准则的内容，并视情况临时或永久限制参与。举报请使用 GitHub 上的私密维护者联系渠道，并明确标记为行为准则报告；不要在公开 issue 中附带敏感证据。

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation for violations. Report conduct issues through a private maintainer contact channel on GitHub and mark the report as a Code of Conduct concern. Do not attach sensitive evidence to a public issue.

维护者会尽量保护举报者隐私，并根据事实、上下文和重复行为采取一致处理。

Maintainers will protect reporter privacy as far as practical and apply consistent handling based on facts, context, and repeated behavior.

This is a short project-specific code of conduct inspired by the Contributor Covenant.
