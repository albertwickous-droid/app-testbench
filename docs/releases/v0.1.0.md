# App TestBench v0.1.0

**首个公开版本 / First public release** · 2026-11-11

**AI 可以写测试，但测试环境不能靠猜。成熟 MuMu 运行时，可重复 App 测试，失败保留原始证据。**

**AI can write the test. It should not guess the test environment. A mature MuMu runtime, deterministic app flows, and raw evidence.**

App TestBench 是一个面向 Android App 的自动化测试工具，MuMu Player 是首个成熟运行时后端。它把 MuMuManager 与 ADB 封装为稳定 CLI，支持 JSON/YAML 流程、UI 断言、截图、UI 树、logcat，以及可直接归档的自包含 HTML 测试报告。

App TestBench is an Android app automation testing tool with MuMu Player as its first mature runtime backend. It wraps MuMuManager and ADB in a stable CLI with JSON/YAML flows, UI assertions, screenshots, UI hierarchy dumps, logcat collection, and self-contained HTML reports.

> 独立开源项目，与网易 / MuMu 官方无隶属关系。仅用于你有权测试的设备、应用和账号。
>
> Independent open-source project, not affiliated with NetEase or MuMu. Use it only with devices, applications, and accounts you are authorized to test.

## Highlights / 主要能力

- **One-shot commands:** `doctor`, instance lifecycle, install, launch, close, tap, swipe, text, keyevent, screenshot, `dump-ui`, and `logcat`.
- **Flow DSL:** versioned JSON/YAML flows with setup, steps, teardown, waits, assertions, environment interpolation, strict validation, and structured failure results.
- **Evidence-rich reports:** every step records status, duration, output, and errors; screenshots and final logs are embedded in a self-contained `report.html`.
- **Machine-readable output:** every command supports `--json`.
- **Agent-ready packaging:** includes a Codex skill at `skills/app-testbench/SKILL.md` and a packaged skill lookup command.
- **Local-first safety model:** no telemetry, no artifact upload, no `shell=True`, escaped report content, and no external assets in reports.

- **一站式命令：** `doctor`、实例生命周期、安装、启动、关闭、点击、滑动、输入、按键、截图、UI 树和 logcat。
- **流程 DSL：** 带版本的 JSON/YAML 流程，支持 setup、steps、teardown、等待、断言、环境变量、严格校验和结构化失败结果。
- **证据报告：** 每步记录状态、耗时、输出和错误；截图与最终日志嵌入自包含 `report.html`。
- **机器可读：** 所有命令支持 `--json`。
- **Agent 可直接调用：** 内置 Codex skill，并提供打包 skill 路径查询。
- **本地优先安全模型：** 无遥测、不上传产物、不使用 `shell=True`、报告内容转义、报告无外部资源。

## Quick start / 快速开始

```powershell
git clone https://github.com/albertwickous-droid/app-testbench.git
cd app-testbench

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .

app-testbench doctor
app-testbench instance list
app-testbench validate .\examples\smoke.yaml
app-testbench run .\examples\smoke.yaml --output .\runs
```

运行目录包含 / A run directory contains:

```text
runs/<timestamp>-<flow-name>/
├── report.html
├── result.json
├── screenshots/
├── ui/
└── logs/
```

## Supported environment / 环境基线

- Windows 10/11
- Python 3.10, 3.11, or 3.12
- MuMu Player with at least one instance
- ADB debugging enabled in that instance
- `MuMuManager.exe` and `adb.exe` discoverable, or supplied explicitly

Linux is covered by the test matrix for code portability, but live MuMu instance management is a Windows workflow.

## Validation / 验证范围

Release checks include:

- Ruff lint and formatting
- Cross-platform CI tests
- Package build
- `twine check`
- Workflow configuration tests

The repository uses deterministic fake `adb` and `MuMuManager` executables for automated tests. CI verifies command construction and artifact behavior, not every MuMu version or every Android app. A live integration test must be performed on the target Windows host.

发布检查包括 Ruff、跨平台测试、构建和 `twine check`。自动化测试使用确定性的假 `adb` / `MuMuManager`，CI 不宣称覆盖所有 MuMu 版本或所有 Android 应用；目标环境仍需要真实集成验证。

## Safety and privacy / 安全与隐私

- Reports can contain account names, chat content, orders, device identifiers, URLs, and tokens from screenshots or logcat.
- Treat `runs/`, screenshots, UI XML, and logcat as confidential evidence.
- The tool does not upload artifacts or collect telemetry.
- Do not commit APKs, real reports, `.env` files, cookies, credentials, or tokens.
- Do not use the project to bypass application security or access accounts/devices without authorization.

- 报告可能通过截图或 logcat 包含账号、聊天、订单、设备标识、URL 和 token。
- 将 `runs/`、截图、UI XML 和 logcat 视为敏感证据。
- 工具不上传产物，不收集遥测。
- 不要提交 APK、真实报告、`.env`、cookie、凭据或 token。
- 不得绕过应用安全机制，或访问未授权的账号/设备。

## Known limitations / 已知边界

- Windows + MuMu Player is the primary supported combination.
- Native `input text` supports printable ASCII only in this release.
- No OCR or image-template matching.
- `uiautomator dump` may not expose text in WebView, games, or custom-rendered surfaces.
- MuMu upgrades may change directories, ports, or MuMuManager output formats.
- Reports are local evidence, not a security boundary.

- 首版主要支持 Windows + MuMu Player。
- 原生 `input text` 仅支持可打印 ASCII。
- 不包含 OCR 或图像模板匹配。
- `uiautomator dump` 可能无法读取 WebView、游戏或自绘界面的文本。
- MuMu 升级可能改变目录、端口或 Manager 输出格式。
- HTML 报告是本地证据，不是安全边界。
